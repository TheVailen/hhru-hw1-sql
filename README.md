# Домашнее задание №1: Введение в SQL

Первое дз для Школы аналитиков hh.ru. В рамках проекта был проведён анализ учебной базы данных с вакансиями и откликами для поиска оптимального направления стажировки в айтишке

## Описание проекта
Основная цель - с помощью SQL-запросов проанализировать рынок стажировок, рассчитать воронку найма (от отклика до приглашения) и на основе данных выяснить, куда выгоднее всего откликаться начинающему специалисту

## Что внутри
* Скрипт с SQL-запросами для извлечения, фильтрации и агрегации данных.
* Поиск и исправление логических и синтаксических багов (ошибки джоинов, деление на ноль, дублирование строк при объединении таблиц).
* Расчет конверсии из отклика в приглашение по различным профессиональным ролям.
* Развернутые продуктовые и аналитические выводы, оформленные в виде комментариев к коду (включая анализ направлений «Тестировщик» и «Аналитик данных»).

## Используемый стек и навыки
* **СУБД:** PostgreSQL
* **Ключевые команды:** `SELECT`, `WHERE`, `GROUP BY`, `HAVING`, `ORDER BY`
* **Соединения таблиц:** `LEFT JOIN`, `INNER JOIN`
* **Конструкции для аналитиков:** `FILTER`, `CASE`, `nullif`, `date_trunc`
